A 100-word villain monologue for make.fun's "The Tired Dark Lord" bounty, $2 in USDC.

## The entry

`main.ts` writes one monologue to `/output/entry.txt` — the Toll-Keeper of the
Drowned Causeway, forty years at his post, collecting memories as tolls and
dreaming of damming the river of the dead. His tiredness lives in the rhythm,
the pauses and the small deflections, never in a plain statement, and the
sting lands in the last line.

The text is exactly 100 words and 509 characters, inside the gate's 1–600
character window. Six candidate monologues were drafted and compared pairwise
against the competition's published judge brief; this one won the round-robin
(0.86) and the two-legged playoff against the runner-up.

## Run it

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_PATH=out/entry.txt node main.ts   # local run
```

Deterministic: no network, no model calls, no randomness, no input.
